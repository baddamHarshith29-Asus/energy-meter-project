# AI-Powered Energy Intelligence & Optimization Platform

A premium web application for analyzing and optimizing energy consumption in offices and factories.

## Features
- **Dashboard**: Interactive data visualization of energy trends and costs.
- **AI Assistant**: Personalized energy saving tips and data explanations.
- **ML Predictions**: Forecast future bills using historical data.
- **Simulation**: Test "what-if" scenarios for energy reduction.
- **Anomaly Detection**: Identify and explain unusual usage spikes.

## Tech Stack
- Frontend: React + Vite + Recharts
- Backend: Flask + Pandas + Scikit-learn + OpenAI
- Database: SQLite (SQLAlchemy)

## Setup
1. Backend: `pip install -r backend/requirements.txt` && `python backend/seed_data.py` && `python backend/app.py`
2. Frontend: `npm install` && `npm run dev` in `frontend` directory.
